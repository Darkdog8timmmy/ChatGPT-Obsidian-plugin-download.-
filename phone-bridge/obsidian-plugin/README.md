# Obsidian Phone Bridge plugin

This folder builds the mobile companion plugin. Copy `main.js` and `manifest.json` into `.obsidian/plugins/obsidian-phone-bridge/` in an Obsidian vault, enable community plugins, then configure the relay URL and pair the phone.

The plugin runs on mobile and desktop, but it only connects while Obsidian is open. It applies note operations locally through Obsidian's vault and editor APIs.
